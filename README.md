# เว็บไซต์ Link-in-Bio สไตล์ Openlink สำหรับครูณัฐภูมิ (Natthapum Art)

## 🚀 วิธีเปิดใช้งาน

1. ดับเบิลคลิกไฟล์ **`index.html`** เพื่อเปิดดูบนบราวเซอร์ (Google Chrome, Safari, Edge) ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่ม
2. หรือใช้ Live Server / Python HTTP Server:
   ```bash
   python3 -m http.server 8080
   ```
   แล้วเปิดบราวเซอร์ไปที่ `http://localhost:8080`
